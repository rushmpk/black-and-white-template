# Black and White Template

A simple and responsive **Black and White Website Template** built using **HTML5** and **CSS3**. This project demonstrates a clean webpage layout with a header, navigation bar, banner, cards, about section, footer, Google Fonts, and Font Awesome icons.

## Features

* Responsive header with navigation menu
* Full-width banner with call-to-action button
* Scrolling announcement (marquee)
* Card layout with images
* About Us section
* Footer with:

  * Quick Links
  * Policies
  * Available Locations
  * Contact Information
  * Social Media Icons
* Google Fonts integration
* Font Awesome icons

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
